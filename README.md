# Banana-Spectral
It's an interactive FORS database supported on a HuggingFace Space. You can navigate trough data on the mode "keyword", for example: "ocre" and Banana spectral will display all spectra with this pigment name. On the other side, you can navigate through different databases (pigment cheker and  USGS Spectral Library). 

Disclaimer: All datasets are property of USGS Spectral Library and Pigment Cheker. Banana Spectral is only an interactive database and any spectra are property of LANCIC-IF.
